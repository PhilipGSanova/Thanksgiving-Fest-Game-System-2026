# Stall Instruction PDFs

Place **one PDF per Game stall** in this folder. Each PDF is opened by the
"Stall Instructions" button on the Games page, which loads the PDF matching
the currently active stall.

## Naming convention

Name each file after the stall's name, with:

- all lowercase
- spaces and any special characters replaced with a single dash (`-`)

Examples of stall name → expected filename:

| Stall name     | Filename                 |
| -------------- | ------------------------ |
| `Ring Toss`    | `ring-toss.pdf`          |
| `Basketball`   | `basketball.pdf`         |
| `Balloon Pop!` | `balloon-pop.pdf`        |
| `Candy Guessing Game` | `candy-guessing-game.pdf` |

If you can't find the expected filename for a stall, just tap the
"Stall Instructions" button on that stall — the app shows the exact
expected path in the error message.
